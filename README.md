# Walls! Alive Website

This is the official website for Walls! Alive, built with Next.js and Tailwind CSS.

## Getting Started

1.  **Install Dependencies:** `npm install`
2.  **Run Locally:** `npm run dev`
3.  **Open:** [http://localhost:3000](http://localhost:3000)

## Updating the Gallery

We use Cloudinary to manage images. This means you don't need to touch the code to add photos.

1.  Log in to your Cloudinary Dashboard.
2.  Go to **Media Library**.
3.  Create a folder named `walls-alive-gallery`.
4.  Drag and drop your project photos into this folder.
5.  Wait up to 24 hours, and they will appear on your website automatically.

## Contact Form

The contact form uses Web3Forms. Responses are sent to `auto_don@zohomail.com`.

## Deployment

This site is optimized for Vercel.
1. Push code to GitHub.
2. Import project in Vercel.
3. Add the Environment Variables (see `.env.local.example`).
